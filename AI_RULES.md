# AI Coding Rules for yol_arkadasim Project

## General Rules
- Keep code simple and readable.
- Do not over-engineer.
- Only modify what is requested.
- Do not add unnecessary features.

## Language Rules
- All comments must be in English.
- Variable, function, class, and file names must be in English.
- UI text can remain in Turkish.

## UI / Design Rules
- When a design reference is provided, match it as closely as possible. Do not redesign.
- Keep layout, spacing, and alignment consistent.
- Use centralized colors, spacing, radius, and text styles when available.
- Do not use random values for padding, spacing, colors, or radius.
- Keep UI clean, simple, and readable.

## Reusable Component Rules
- Extract repeated UI elements into reusable widgets.
- Do not duplicate similar UI components.
- Keep widgets small and focused.

## File Scope Rules
- Do not modify unrelated files.
- Do not change navigation unless explicitly requested.
- Do not rename files without a clear reason.
- Do not create unnecessary files.
